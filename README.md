💍 Convite de Casamento Digital

Um convite de casamento moderno, elegante e totalmente interativo desenvolvido para facilitar a confirmação de presença e compartilhar detalhes desse dia tão especial.

______________________________________________________________________________________________________________________________________________________________________________________________

🚀 Sobre o Projeto

Este projeto nasceu da ideia de criar uma experiência única e acessível para os convidados. O site funciona como um convite digital dinâmico onde os amigos e familiares podem visualizar 
informações cruciais sobre o evento e interagir diretamente com a página.

✨ Funcionalidades principais:
- Design Responsivo:** Adaptado perfeitamente para visualização em celulares, tablets e computadores.
- Confirmação de Presença (RSVP):** Sistema integrado para que os convidados possam confirmar a presença de forma rápida.
- Página de Agradecimento:** Tela de feedback (`obrigado.html`) após a interação do convidado.
- Informações do Evento:** Seções dedicadas à data, horário, localização (com mapa integrado) e contagem regressiva.

______________________________________________________________________________________________________________________________________________________________________________________________

🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias de front-end:

* **HTML5:** Para a estruturação semântica e acessível de todo o conteúdo das páginas.
* **CSS3:** Responsável por toda a estilização, layout responsivo (Flexbox/Grid), tipografia e transições suaves.
* **JavaScript (Vanilla):** Utilizado para adicionar interatividade, como a contagem regressiva para o grande dia e manipulação do formulário de confirmação.
